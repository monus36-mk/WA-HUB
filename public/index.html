Developer REST API Reference

Integrate WhatsApp messaging into any e-commerce platform, CRM, or backend microservice.

POST http://localhost:5001/api/send

Send plain text message to any phone number.

curl -X POST http://localhost:5001/api/send \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "919876543210",
    "message": "Hello from API! Your order is ready."
  }'
POST http://localhost:5001/api/templates/cod-confirm

Triggers structured COD verification message.

curl -X POST http://localhost:5001/api/templates/cod-confirm \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "9876543210",
    "customerName": "Rahul Sharma",
    "orderId": "1049",
    "amount": 899,
    "address": "42 MG Road, Bengaluru"
  }'
Node.js / Browser (Fetch)
